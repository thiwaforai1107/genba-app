# 西島塗装 現場支援アプリ（ご提案デモ）

有限会社 西島塗装（熊本県玉名市）向けの、現場支援アプリのデモです。
1つのアプリの中で、使う機能を選べます。スマホでの操作を最優先に作り、PCでは社長・事務所向けの広い画面になります。

| 機能 | 内容 | 元になったもの |
|---|---|---|
| 出退勤 | 現場を選んで打刻（直行直帰向け）・現場からの距離・雨天中止・退勤時の日報・月の集計とCSV | 模擬案件5（勤怠管理）を塗装現場向けに作り替え |
| 現場写真 | 工程を選んで撮る・撮るものリスト（撮り漏れ防止）・着工前／前の塗りと同じ構図で撮れる重ね表示・電子黒板風・水平器・端末内で縮小・まとめて送信 | 模擬案件4（現場写真管理）を塗装・防水の工程に合わせて作り替え |
| 写真台帳 | 現場・工程・部位・撮影者・期間で検索、アルバム掲載／発信候補の切り替え、着工前との比較 | 同上 |
| 工事アルバム | お客様がURLを開くだけで工程順の写真・3回塗りの記録・ビフォーアフター・口コミのお願い | ご提案書 PLAN B |
| 発信の下書き | 写真と工程の記録から、ホームページ施工事例・Instagram・Googleマップ・求人の文章を一度に作成 | ご提案書 PLAN A |
| 社長ダッシュボード | 今日の出勤・現場の進み具合・撮り漏れ・日報・塗装条件（天気）・月次レポート・お客様の声 | ご提案書 PLAN C |

メニュー →「使う機能を選ぶ」で、機能ごとにON/OFFできます。

## 現場写真の工夫（塗装の現場に合わせたところ）

- **工事の種類ごとに工程ボタンが切り替わる**：外壁・屋根塗装／屋上防水（ウレタン通気緩衝）／鉄部／シーリング
- **撮るものリスト**：工程ごとに「何を撮るか」が決まっていて、撮ると次へ自動で進む。撮り漏れは現場画面と社長ダッシュボードに出る
- **同じ構図で撮れる**：着工前の写真（中塗り・上塗りでは前の塗り工程の写真）を半透明で重ねて表示。ビフォーアフターがきれいにそろう
- **3回塗りの記録**：部位（外壁・屋根）ごとに、下塗り・中塗り・上塗りの写真がそろっているかを会社マークの3本線で表示
- **乾燥時間の目安**：塗り工程の最後の写真から、次の工程まであと何時間かを表示
- **塗装できる天気か**：玉名市の気温・湿度・降水確率から「塗装OK／注意／見合わせ」の目安を表示（Open-Meteo）
- **お客様の名前はファイル名に入らない**：`N015_下塗り_外壁_20261029_0942.jpg` の形に自動で付け替え
- **是正の写真はお客様に見せない**：アルバムには自動で載らない
- **公共工事の線引き**：提出用の工事写真は改ざん検知に対応した電子小黒板アプリで撮影。このアプリは撮影計画・撮り漏れ確認・社内共有・広報用

## デモの進め方（約10分）

1. **PCでホームを見せる**（ブラウザを横に広く）。左のメニューで機能が並んでいることを確認
2. 左下の「**スマホで体験する**」でQRを出し、西嶋様のスマホで読み取ってもらう
3. **スマホ：出退勤** → 「出勤」を押す（現場からの距離が出る）
4. **スマホ：撮影（真ん中のオレンジのボタン）** → 下塗りが選ばれている → 撮るもの「外壁 塗装中」を撮る → 自動で次の撮るものへ → 「送る」
5. **PC：現場一覧 → 長洲町 N事務所** → 3回塗りの線と、撮り漏れの赤い表示、乾燥時間の目安を見せる
6. **PC：工事アルバム → 玉名市岱明町 F様邸**（完成現場）→ ビフォーアフターのつまみを動かす、3回塗りの記録、口コミのお願い
7. **PC：発信の下書き** → 「下書きを作る」→ ホームページ・Instagram・Googleマップ・求人の4種類がそろう
8. **PC：社長ダッシュボード** → 今日の現場・日報・月次レポート
9. 最後に **メニュー →「使う機能を選ぶ」** で、必要な機能だけを選んで導入できることを見せる

デモを最初の状態に戻すときは、メニュー →「デモを最初の状態に戻す」。

> スマホとPCは、そのままではそれぞれの端末の中だけで動きます。**スマホで撮った写真をPCに出す**には、下の「スプレッドシート連携」をつなぎます。

## 公開（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの Settings → Pages → Branch を `main`／`/(root)` にして保存
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける（カメラはHTTPSで動きます）

`index.html` に `noindex` を入れているので、検索エンジンには載りません。

## スプレッドシート連携（PCとスマホで同じデータを見る）

1. Googleドライブで新しいスプレッドシートを作る →「拡張機能」→「Apps Script」
2. `gas/Code.gs` の中身を貼り付け、`gas/appsscript.json` の内容をマニフェストに反映（プロジェクトの設定で「appsscript.json を表示」をON）
3. 関数 `setup` を1回実行（承認画面が出たら許可）。ログに **合言葉（APP_KEY）** が出る
4. 「デプロイ」→「新しいデプロイ」→ 種類：ウェブアプリ／実行ユーザー：自分／アクセス：全員 → URL（…/exec）をコピー
5. アプリの メニュー →「スプレッドシート連携」に URL と合言葉を入れて「接続する」。PCとスマホの両方で行う

写真は「西島塗装 現場写真／現場ID／工程」のフォルダに保存され、「写真台帳」シートに1行ずつ記録されます。
6秒ごとにほかの端末の写真・打刻を取り込みます。電波がない場所で撮った写真は、つながったときに自動で送ります。

## ファイル構成

```
index.html              入口
assets/css/app.css      デザイン（色・書体はホームページと共通）
assets/js/app.js        画面の切り替え・ホーム・現場・メニュー
assets/js/field.js      出退勤
assets/js/camera.js     現場写真の撮影
assets/js/office.js     写真台帳・社長ダッシュボード
assets/js/customer.js   工事アルバム・発信の下書き
assets/js/store.js      データの保存・天気・GAS連携
assets/js/data.js       会社情報・工程の定義・デモデータ
assets/demo/            デモ用の写真（御社ホームページ掲載の施工写真）
assets/vendor/qrcode.js QRコード生成（MIT, Kazuhiko Arase）
gas/                    スプレッドシート連携（Google Apps Script）
sw.js / manifest        ホーム画面に追加・電波が弱くても開ける
```

## 注意

- デモの写真は、御社ホームページに掲載済みの施工写真を、工程の例として組み合わせています（別の現場の写真が混ざっています）
- 職人名・現場名・数値（月次レポートなど）はデモ用です
- 発信の下書きは、デモでは定型の組み立てです。本番は生成AI（Gemini）で御社の言葉づかいに合わせて作ります。投稿は必ず人が確認してから行います
- 給与額の計算は行いません（勤怠は集計とCSV出力まで）
